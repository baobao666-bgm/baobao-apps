# Twinkstar（星愿浏览器）

> 返回 [README](../README.md)

安装包约 125 MB。

## 解包说明

星愿的安装包是带签名尾部的 NSIS（7-Zip 无法自动识别格式），manifest 以 `-tNsis` 显式解包并取出其中的完整程序文件；安装过程不写注册表、不弹安装向导。

## 快捷方式说明

开始菜单会创建「星愿浏览器」快捷方式。该名称为中文，在非中文 ANSI 代码页的系统上会因 WScript.Shell 平台限制被跳过（stderr 出现一条非致命错误，**安装本身照常成功**，仅缺快捷方式）；中文系统上正常创建。

## 常见问题

- **一启动就闪退（日志报 `GPU process exited unexpectedly`）**：多见于旧显卡驱动或精简系统（GPU 进程沙箱初始化失败）。建议先升级显卡驱动、检查系统更新；确需临时绕过时，可在快捷方式「目标」末尾追加 `--disable-gpu-sandbox`（或命令行执行 `twinkstar --disable-gpu-sandbox`）——该参数会降低渲染进程隔离，仅作排障用，不建议长期使用。
